Setting up a screen

  • Raspberry Pi: run scripts/pi-display-setup.sh on the Pi (Raspberry Pi OS Lite is enough). It installs a minimal kiosk that boots straight into this display and restarts it if anything crashes. Pass the display URL from the table above.
  • ESP32: flash the ESPHome config in examples/esphome-tdisplay.yaml (LILYGO T-Display) or examples/esphome-display.yaml (generic), pointing it at the API URL above.
  • Android TV: enable Developer options and Network debugging on the TV, add it here with its IP, then press Show. The first Show pops an "allow USB debugging" prompt on the TV: tick Always allow. The TV needs a browser that can open links (most Google TVs ship Chrome; sideload one otherwise).
